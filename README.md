El problema que resuelve el programa es, conocer cuánto debe pagar un cliente cuando compra varias unidades de un producto.

Primero tenemos la función llamada calcular_total. Esta función recibe dos parámetros: precio y cantidad.

Dentro de la función se realiza la multiplicación del precio por la cantidad y el resultado se almacena en la variable total.

Después utilizamos la palabra return, que permite devolver el resultado de la operación.

Fuera de la función, el programa solicita al usuario que ingrese el precio del producto y la cantidad que desea comprar.
